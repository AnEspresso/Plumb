# The Book Walk

Say **“run the Book Walk”** and this is what we run.

A full public-facing QA, **forward and back**, on every hat. Catchy name, pinned.

| Hat | Login |
|---|---|
| Marketing | siteplumb.com — no version bar, no walk |
| Demo | Example build — no “show me around” unless QA |
| Builder | `pmgottschalkqa@gmail.com` |
| Team | `pmgottschalkqa+team@gmail.com` |
| Homeowner | `pmgottschalkqa+home@gmail.com` |
| Sub | `pmgottschalkqa+sub@gmail.com` |

**Forward:** sign in → home → a house → doors (Schedule, Selections, Money, Field Notes) → Full site → Company → Settings → back out the same way.

**Back:** every sheet dismisses to the place you came from. No dead ends.

**Always check:** Field Notes send, add-a-house, website lookup + scan card, packet, no walk rows for the public, no Workbench except QA.

**Website lookup rule:** fill only what we can prove (Places + their site). Blank is better than a guess. McCarver Mechanical must land HVAC + phone + website, never Excavation.

**Scan card:** camera on the phone (`capture=environment`). OCR fills email/phone/site when the photo is sharp. Always check the card.

Script: `node scripts/book-walk.mjs`
